# 🎮 Ganesha's Missing Modak

## 🪔 A Ganesh Chaturthi Mystery Adventure

The special Modak is missing! 🍬

Help Ganesha find the missing Modak by completing three fun festival challenges.

## 🎯 How to Play

### 🌺 Level 1: Flower Hunt
Collect all 5 flowers for Ganesha's Puja.

### 🍬 Level 2: Modak Puzzle
Find Ganesha's special Modak from the given choices.

### 🪔 Level 3: Festival Puzzle
Choose the Puja items in the correct order.

## ⭐ Features

- 3 interactive game levels
- Score system
- Level progress bar
- Interactive puzzles
- Animations and visual effects
- Ganesh Chaturthi theme
- Final victory screen
